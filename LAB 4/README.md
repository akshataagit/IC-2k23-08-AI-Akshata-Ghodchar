
# Experiment 13: Knowledge Representation

## Aim
To implement Knowledge Representation in
Artificial Intelligence using Python.

## Introduction
Knowledge Representation is the process of
representing real-world information in a format
that computers can understand and process.

It allows AI systems to store facts, relationships,
objects and rules for reasoning.

## Types of Knowledge Representation

1. Logical Representation
2. Semantic Networks
3. Frames
4. Production Rules

## Implementation
In this experiment, knowledge about students
is represented using Python dictionaries.

Each student has attributes such as:
- Name
- Age
- Course
- Subject
- Marks

The program retrieves information, applies
simple reasoning and adds new knowledge.

## Python Concepts Used
- Dictionaries
- Nested Dictionaries
- Loops
- Conditional Statements
- Key-Value Pairs

## Execution
python Experiment13.py

## Result
Knowledge Representation was successfully
implemented using Python dictionaries.




# Experiment 14: Rule-Based Systems

## Aim
To implement a Rule-Based Expert System
using Python.

## Introduction
A Rule-Based System is an Artificial Intelligence
system that uses predefined IF-THEN rules
to make decisions.

It consists of:
1. Knowledge Base
2. Rule Base
3. Inference Engine
4. User Interface

## Working
The system accepts symptoms from the user
and checks them against predefined rules.

Based on the matching conditions, it generates
a corresponding output.

## Rules Used

Rule 1:
IF fever AND cough AND cold
THEN Flu-like illness.

Rule 2:
IF fever AND headache
THEN Fever with headache.

Rule 3:
IF cough AND cold
THEN Common cold.

Rule 4:
IF headache
THEN Headache.

## Python Concepts Used
- Input and Output
- Conditional Statements
- IF-ELIF-ELSE
- Logical Operators
- String Functions

## Execution
python Experiment14.py

## Result
A Rule-Based System was successfully
implemented using Python and IF-THEN rules.




# Experiment 15: Semantic Networks

## Aim
To implement Semantic Networks using Python
for knowledge representation.

## Introduction
A Semantic Network is a graphical technique
used to represent knowledge in Artificial Intelligence.

It consists of nodes and edges.

Nodes represent objects or concepts, while
edges represent relationships between them.

## Components

1. Nodes: Represent objects or concepts.
2. Edges: Represent relationships.
3. Labels: Describe the type of relationship.

## Relationships Used

- IS-A: Represents inheritance or category.
- HAS-A: Represents possession.
- CAN-DO: Represents an ability.
- NEEDS: Represents a requirement.

## Implementation
A semantic network is created using Python
dictionaries.

The program stores relationships between
Dog, Cat, Mammal and Animal.

It also searches and displays relationships.

## Python Concepts Used
- Dictionaries
- Nested Dictionaries
- For Loops
- Functions
- Conditional Statements

## Execution
python Experiment15.py

## Result
Semantic Networks were successfully implemented
using Python to represent relationships between
different concepts.
