# AILab

## 📌 About the Repository

This repository contains practical implementations of Artificial Intelligence (AI) and Machine Learning (ML) concepts using Python. It is organized lab-wise and includes programs, datasets, trained models, documentation, and project resources.

The main objective of this repository is to understand and implement fundamental AI and ML algorithms through practical experiments. It covers problem-solving techniques, search algorithms, data preprocessing, knowledge representation, and machine learning models.

This repository is developed as part of academic laboratory work to gain hands-on experience with AI and ML concepts.

---

## 🎯 Objectives

- Understand the fundamental concepts of Artificial Intelligence and Machine Learning.
- Implement different AI search and problem-solving algorithms.
- Perform data preprocessing and exploratory data analysis.
- Understand knowledge representation and rule-based systems.
- Implement machine learning algorithms for classification and prediction.
- Evaluate machine learning models using performance metrics.
- Work with datasets, Python libraries, and trained ML models.
- Develop practical problem-solving and analytical skills.

## 🧪 Lab Experiments

### Lab 1: Introduction to Artificial Intelligence

This lab focuses on introductory AI concepts and basic problem-solving implementations using Python.

**Files:**
- `Experiment1.ipynb` – Introduction to AI concepts and practical implementation.
- `Experiment2.py` – Python implementation of the assigned AI experiment.
- `outputs/` – Stores program outputs and screenshots.

### Lab 2: Search Algorithms

This lab covers different search techniques used in Artificial Intelligence to find solutions to problems.

**Topics include:**
- Breadth First Search (BFS)
- Depth First Search (DFS)
- Hill Climbing
- Best First Search
- A* Search
- Water Jug Problem

**File:** `SearchAlgorithms.py`

### Lab 3: Data Preprocessing and Exploratory Data Analysis

This lab focuses on preparing raw datasets for machine learning and understanding data through analysis and visualization.

**Topics include:**
- Data Cleaning
- Handling Missing Values
- Data Transformation
- Data Encoding
- NumPy
- Pandas
- Exploratory Data Analysis (EDA)
- Data Visualization

**File:** `DataPreprocessing.ipynb`

### Lab 4: Knowledge Representation

This lab explores different techniques used to represent knowledge and reasoning in Artificial Intelligence systems.

**Topics include:**
- Knowledge Representation
- Rule-Based Systems
- Semantic Networks
- Facts and Rules
- Logical Reasoning

**File:** `KnowledgeRepresentation.ipynb`

### Lab 5: Machine Learning – Decision Tree

This lab introduces supervised machine learning and classification using the Decision Tree algorithm.

**Topics include:**
- Introduction to Machine Learning
- Supervised Learning
- Decision Tree Classifier
- Model Training and Testing
- Feature Importance
- Model Evaluation
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

**File:** `DecisionTree.ipynb`

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/akshataagit/IC-2k23-08-AI-Akshata-Ghodchar.git
```

### 2. Navigate to the Project Directory

```bash
cd AI-ML-Lab
```

### 3. Create a Virtual Environment (Optional)

```bash
python -m venv venv
```

Activate the environment:

**Windows:**
```bash
venv\Scripts\activate
```

**Linux / macOS:**
```bash
source venv/bin/activate
```

### 4. Install Required Dependencies

```bash
pip install -r requirements.txt
```

### 5. Launch Jupyter Notebook

```bash
jupyter notebook
```

Open the required lab folder and execute the notebook cells.

## ▶️ How to Run the Experiments

1. Clone or download the repository.
2. Install Python and the required dependencies.
3. Open the repository in VS Code, PyCharm, or Jupyter Notebook.
4. Navigate to the required lab folder.
5. Open the `.py` file using VS Code.
6. Execute the notebook cells sequentially.
7. For standalone Python programs, run:

```bash
python Experiment2.py
```

8. Check the `outputs/` folder for saved experiment results, where applicable.
